1. COMPLETED CHANGES AND AFFECTED SOURCE FILES
native-ios/renderer/native_queries.inc implements real query creation, Begin,
End, per-pass resolution, compact copies, asynchronous maps and reply delivery.
Each physical pass snapshots actual samples before a later pass; results map
only after the matching draw encoder is submitted. Overlapping logical scopes
receive their own intervals. Monotonic tokens prevent reuse and object-ID ABA
from publishing old results. Destruction retires reply ownership BEFORE a
destruction-triggered flush can process callbacks. Unended scopes never publish
fake completion. Map contexts live through instance release during cancellation.

query_state.h and query_types.inc hold the logical state and fixed four-page
pool. Each page contains 64 query slots, a 16 KiB aligned resolve buffer and a
512-byte compact map buffer; maximum logical GPU payload is 68 KiB, excluding
driver overhead. Up to 32 overlapping scopes are supported. UINT64 accumulation
uses defined unsigned wrap as D3D specifies. Predicates preserve any nonzero
segment even if the accumulated count wraps to zero. Ordering and bounds errors
remain fatal; unsupported operations do not return fabricated success.

native_draw.inc and native_gpu.m attach query sets, end passes in order, submit
and poll maps, preserve fences and existing uniform-slot synchronization, and
reacquire the page after a uniform-overflow flush before constructing bindings.
There is no completion wait added to each occlusion End. Four-page pressure
is bounded/cancelable and reported. Idle polling is 2 ms only with pending maps,
otherwise the previous 100 ms. Reports retain fatal operation/shader/payload,
bindings and eight recent command breadcrumbs, plus bounded query statistics.

patch-metal-bc.mjs changes one content-pinned HAL begin_query site from Boolean
to Counting. Actual Apple3/Mac2 hardware support is required at runtime; no
adapter limit or unavailable feature is fabricated. Existing adapter/Naga
patches remain unchanged. Cargo checksums/evidence and dependency cache keys
describe the changed source. QuerySet cleanup releases its exclusively owned
public reference once: in pinned native 29.0.1.1, Destroy and final Release both
call the core drop, which independently reproduced a vacant-resource panic.
In-flight command buffers retain their internal resource references.

draw_pipeline.inc now rejects partial/zero fixed sample masks that disable
relevant samples. The pinned Metal HAL silently ignores multisample.mask; a
real four-sample test returned 1024 where the mask required 512. Masks with all
relevant bits set remain supported. This is an explicit unsupported boundary,
not a mask implementation. No ignored mask or invented count is accepted.

New tests: test_query_state.c, query_setup.inc, query_replay.inc,
query_fixture.inc and query_stop_fixture.inc. build-renderer.sh runs the state
test with ASan/UBSan. App.m / generate-probe.mjs increase the bounded GPU report
to 8192 bytes and label 0.20; Info.plist uses 0.20.0/build 20 and the same bundle.
source-manifest.json lists 133 files. Seventeen entries changed versus 0.19,
including the manifest; eight source files are new. Engine, host, worker,
archive reader, original shader files and 0.19 shader/upload fixes are preserved.

2. PROTOCOL AND SOURCE EVIDENCE
The approved wgpu_worker.js reference defines CREATE_QUERY44(id,type,replyLow,
replyHigh), BEGIN_QUERY45(id) and END_QUERY46(id,completionSequence). Replies
use 16 bytes: done at +0, reserved +4 untouched, UINT64 low/high at +8/+12.
Value words precede a release completion store and native notification. Type1
returns real samples; type5 returns canonical BOOL. The browser's visible
65536 substitution is not used. Occlusion is core WebGPU query functionality;
no optional timestamp feature or arbitrary hardware-limit increase is needed.

The supplied physical BEGIN ID11165 proves the previous unsupported path, but
its CREATE type and following geometry/render state were not supplied. Both
type1 and type5 are tested. The bound hashes identify clouds_anim
VSCloudsVertScatterPiercing_Infinite and clouds_altitude PSClouds_Cheap.
Independent source reflection checks 11 VS outputs and seven PS inputs with
matching types/interpolation. The retained 0.19 linker moves location15 to10;
all outputs fit15. This is source-only evidence, not that actual scene pair's
full pipeline/draw verification. The audit helper initially matched main_inner
and then checked raw sparse labels; corrected entry reflection/remapping passed.
