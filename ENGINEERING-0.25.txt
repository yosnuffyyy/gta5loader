   original view dimension, multisampling, overflow-safe mip/layer bounds,
   remaining-subresource ABI, cube square faces and cube-array face count.
   Cube-array first face need not be divisible by six; count must be.

   nonzero handles fail explicitly; genuine unbound zero remains separate.
   All metadata remains owned by the existing GPU consumer thread.

   aspect/sample compatibility is validated before native view creation.
4. Color-to-depth proxies honor the declared linear/sRGB view encoding.
   Separate bounded cache entries avoid reusing one encoding's depth values
   for the other. Content writes refresh both correctly when subsequently used.

   unused zero count selects one layer, instead of affecting adjacent slices.
