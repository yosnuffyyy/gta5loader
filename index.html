Set up on iPhone
Already installed? Tap Update engine support if offered. This update downloads a replacement engine (about 66 MB) and keeps your installed game files. Play offline starts the Prologue with the minimal profile: 512×288 at 30 FPS, shorter draw distance, no optional DLC, random traffic, pedestrians or ambient events. Mission characters and audio remain enabled. If the browser restarts a game session, a recovery screen pauses the next attempt and preserves its last loading details.


  1. Open this HTTPS setup page in Safari. Use Share → Add to Home Screen, with Open as Web App enabled if offered.
    2. 

  2. Open the new Home Screen app before installing the files. Its storage may be separate from Safari's tab.
    3. 

  3. Tap Check this device, then import your existing web folder from Files or a connected USB drive. Keep Wi-Fi on during import: the compatible engine and support scripts, including audio (about 67 MB total), download automatically. Game data is read locally. Missing optional artwork or duplicate shader files will not block playing.
    4. 

  4. Keep this app visible and the phone unlocked while copying. You can pause and resume. When it says Installed or Ready to play, use Play offline. Files that could not be imported are listed separately, and the rest of the import continues.


Allow about 22 GB for the installed game, plus free space for saves and iOS. Importing from a folder already copied onto the phone temporarily needs room for both copies. Importing from a USB drive avoids that duplicate phone copy.


This edition uses converted 32-bit WebAssembly memory with a 512 MB initial allocation and a 4 GB ceiling. It no longer needs Memory64. WebGPU and sufficient runtime memory are still required. The minimal engine is being tested to address the iPhone restart. Successful desktop gameplay does not establish iPhone compatibility. This launcher starts a new Prologue session instead of automatically loading the saved downtown scene; normal game autosaving can still occur.




Keep this Home Screen app and its original website address. Clearing website data removes the installed files and may remove saves. Storage persistence is requested, but iOS can still impose storage limits.
