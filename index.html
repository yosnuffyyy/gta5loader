Set up on iPhone

  1. Open this HTTPS setup page in Safari. Use Share → Add to Home Screen, with Open as Web App enabled if offered.
  2. Open the new Home Screen app before installing the files. Its storage may be separate from Safari's tab.
  3. Tap Check this device, then import your existing complete web folder from Files or a connected USB drive. Keep Wi-Fi on during import: the compatible engine (about 66 MB) downloads automatically; the game data is read locally.
  4. Keep this app visible and the phone unlocked while copying. You can pause and resume. When it says Installed, turn off the setup server and use Play offline.

Allow about 22 GB for the installed game, plus free space for saves and iOS. Importing from a folder already copied onto the phone temporarily needs room for both copies. Importing from a USB drive avoids that duplicate phone copy.

This edition uses converted 32-bit WebAssembly memory with a 512 MB initial allocation and a 4 GB ceiling. It no longer needs Memory64. WebGPU and sufficient runtime memory are still required. The converted engine has rendered Story Mode on a desktop; physical iPhone gameplay is not yet verified.

Keep this Home Screen app and its original website address. Clearing website data removes the installed files and may remove saves. Storage persistence is requested, but iOS can still impose storage limits.

This setup website imports game data from your local web folder and downloads its compatible engine once. The setup website is needed once. Opening this HTML file directly in Files cannot install the offline handler.
