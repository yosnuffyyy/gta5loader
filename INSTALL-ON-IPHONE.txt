NATIVE INTEGRATION 0.20 — WINDOWS INSTALLATION

Install GTA-Native-Probe-0.20-unsigned.ipa over the existing native app using
your usual local signing tool, the same Apple account and bundle identifier.
Keep your extracted web folder and existing installation. No game-file or
Windows prerequisite reinstall is needed. All 19 older IPAs are preserved.

When you can test, select your existing web folder and tap Trace Prologue
startup. Keep the game view visible. Check whether actual characters/world,
camera movement, textures and animation appear after North Yankton and
continue for roughly two minutes. Tap Stop and copy the full final report,
including negotiated varying/clip/border limits, presented-pixel samples,
logical GPU allocation trends and any fatal operation/binding breadcrumbs.
The scene gate is stage 3. Audio output and game controls remain stage 4.

Optional diagnostic button: Run GPU queue + startup tests includes 180 actual
query cases, cancellation and eight error boundaries, plus varying
location/flat/clip pixel checks and byte-update/copy/resolve checks. CI passed
two full runs and the exact Prologue shader pair under 15 varying slots. Its fixture
pixels and first-archive checkpoint are separate from a real game scene.
Required unported operations still stop with detailed diagnostics.
See VERIFICATION-0.20.txt and ENGINEERING-0.20.txt. No physical 0.20 scene or
responsive controls are claimed by the CI/IPA audit.

This is a native engine diagnostic app. It does not launch GTA gameplay yet.
It is separate from both the working PC game and the Safari installation.

1. The windows folder contains Apple's iTunes64Setup.exe and iCloudSetup.exe
   linked by Sideloadly, plus SideloadlySetup64.exe from https://sideloadly.io/ .
   Install the Apple prerequisites, then Sideloadly, following their prompts.
   Follow the site's Windows prerequisites for Apple's web iTunes/iCloud
   versions. Do not uninstall existing Apple software without checking those
   instructions and your sync/backup needs.
2. Connect your unlocked iPhone by USB and trust this computer on the phone.
3. Open Sideloadly, select your phone, and choose GTA-Native-Probe-0.20-unsigned.ipa.
4. Use the normal Apple ID signing/install mode with your free Apple account.
   Enter the password and any two-factor code only in the local signing tool.
   No account credentials, certificates or private keys belong in GitHub.
5. Install. If requested, enable Developer Mode in iPhone Settings > Privacy
   & Security, and trust your developer profile in Settings > General >
   VPN & Device Management. Follow the iPhone's restart/confirmation prompts.
6. Open GTA Native Probe, tap Check local web folder and select the extracted
   web folder in Files. It must contain data/manifest.json and game files.
   Tap Trace Prologue startup and copy its report. If iOS closes the app, reopen
   it and copy the retained report.
7. The separate Run native engine tests button retains the basic converted
   engine and Metal diagnostic. The older renderer and worker tests remain
   available for regression checks. None starts verified gameplay. Folder checks
   and asset tests use bounded sample reads; no 21 GB copy or installation
   happens in this prototype.
   Safari's private installed-file storage is not accessible to a native app;
   select the original extracted folder in Files, if you still have it.
8. Optionally pair a controller in Settings > Bluetooth. Return to the app
   and press its primary face button (PlayStation Cross / Xbox A).

No JIT activation is required: the engine is compiled to ARM64 ahead of time.
No special increased-memory entitlement is requested in this diagnostic app.
Native apps still have iOS memory limits; this build does not bypass them.

Free-account signing lasts seven days. Sideloadly can refresh the app when
your computer and phone are connected; it does not require the computer to
stay on while you use the app. Keep the same account and app identifier
when refreshing. The original PC port and Safari game are separate apps.
