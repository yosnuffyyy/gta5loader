FIXED AND INDEPENDENTLY VERIFIED
The reported 5632/5633 mismatch was a Native0.25 validation regression.
The original SRV is a TEXTURE2D view of a one-layer BC3 image; the original
im/PS_BlitTexArray shader expects texture_2d_array<f32>. A single selected
2D layer is valid for an array shader. Native0.25 required identical view
and shader enum values and rejected it before constructing the valid view.
The common contract now accepts 2D/2D-array views within the same resource
family, preserving the selected range. Non-array shaders still require
exactly one selected layer. Cube, 3D, multisample, numeric type, format,
mip/layer bounds and source-generation checks remain enforced.

The shader pair is VS4e1d5d361e0ed0bc (im/VS_Blit) and
PS57bf4a9b8c9330c5 (im/PS_BlitTexArray). Group1 binding39 maps to slot7.
Its sample type is float; native dimension3 means2DArray, not3D.
The original dynamic layer comes from cb5 element3.w and remains intact.
No shader specialization, texture replication, fabricated layers, discarded
sample or additional CPU/GPU synchronization is used by this fix.

The fixture uses the exact original shader sources and reported SRV words
[5633,0,5632,77,4,0,5,0,0]. It reconstructs the64x64 one-layer/five-mip
resource and uploads five deterministic BC3 payloads, reaching version6.
The phone's actual texture bytes, constants, vertices and complete command
stream were not supplied. This is a targeted production-consumer regression,
not a full captured Prologue replay or proof of the original scene pixels.
See evidence/0.26/local-root-cause.txt for the specification and trace.
