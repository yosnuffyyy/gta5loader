## Implemented changes
- V2 event ENDs now form bounded logical fences instead of flushing every pending draw. At most128 deferred/in-flight replies combined;32 deferred events or1ms checked between commands, dependency/pressure/idle flushing. No dependence on PRESENT. Actual GPU completion, original timestamp compatibility values, token/generation checks and occlusion remain intact. Existing backend stays available/default.
- Matched replay now measures whole service-loop active CPU as well as inclusive opcode costs, so moving work into drain handling cannot be reported as a fake CPU saving. Profiling off adds no new clock reads for the deadline; the existing command timestamp is reused.
- Startup-only Low640x360 / Potato480x270 / Ultra Potato320x180. 16:9 throughout engine arguments, published input and native surface; no unsafe mid-session resizing. HUD also uses reduced resolution. No unverified below-minimum quality values or population writes are shipped. Ambient-density reduction remains blocked on establishing original frame-reset/mission ordering; existing low settings retained.
- Pre-game Story/Sandbox selection uses original engine startMode1/2, no invented flag. Sandbox uses NativeSandboxProbe save root, Story retains NativeRuntimeProbe. Preferences persist and are disabled while busy. Original Story startup retains its existing noautoload behavior; no new checkpoint/autosave loader is claimed. Original selector12checks passed locally; complete free-roam initialization still requires device verification.
- Fixed a stop/catch race: native_thread_tick could intentionally trap on scene_stop before runtime.stopping became true, while catch classified it as a worker failure. Intentional cancellation is now explicitly tagged at its originating trap; real unreachable traps remain failures, even during shutdown. Native0.40 log records Stop/stop1 immediately before worker trap; this is evidence consistent with the race, not proof excluding another engine failure. Entry15 maps to rage::sysIpcThreadWrapper, not the underlying faulting function. Bounded pre-unwind native trace offsets are captured for future genuine failures; match retained IPA UUID/symbols.
